# My GUVI Python Project

A collection of Python and Jupyter Notebook projects developed while learning and practicing **Data Analysis with Python**.

This repository focuses on practical applications of **Pandas, data cleaning, data manipulation, data exploration, and data visualization** using real-world datasets and examples.

## 📌 Project Overview

The main objective of this repository is to build a strong foundation in Python-based data analysis by working with datasets and applying different data processing techniques.

The notebooks cover:

- Data Cleaning
- Reading and Loading Data
- Pandas Indexing
- Data Selection and Filtering
- Data Manipulation
- Data Visualization
- Exploratory Data Analysis

## 📂 Repository Contents

| Notebook | Description |
|----------|-------------|
| `Data Cleaning.ipynb` | Techniques for cleaning and preparing datasets for analysis |
| `Pandas 101 - Reading in Pandas.ipynb` | Reading and loading datasets using Pandas |
| `Pandas 101 - Indexing in Pandas.ipynb` | Understanding indexing, selection, and accessing data |
| `Pandas 101 - Visualizing Data.ipynb` | Creating visualizations to understand and communicate data |
